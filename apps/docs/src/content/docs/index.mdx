## In your backend

A few calls take a customer from nothing to an agent running with their own accounts.

```ts title="server.ts"
import { createClient, createHttpTransport } from "@zupflow/sdk";

const zupflow = createClient(
  createHttpTransport({ baseUrl, getToken: async () => apiKey }),
);

// One workspace per customer, with your own ID for them.
const ws = await zupflow.workspaces.create(orgId, {
  name: "Acme",
  slug: "acme",
  environment: "production",
  external_id: "cus_1042",
});

// Link their Linear account through hosted Connect.
const connect = await zupflow.connectSessions.create(
  ws.id,
  { app_id: linearId, intent: "create", label: "Linear",
    installation_id: null, return_url: returnUrl },
);

// Run an agent with the tools you granted it.
await zupflow.runs.create(ws.id, agentId, {
  input: "Move overdue issues to next sprint.",
});
```

## Built for production

<dl class="zf-home-list">
  <div>
    <dt>Isolation by design</dt>
    <dd>Organization and workspace scopes are explicit in every query, key and test.</dd>
  </div>
  <div>
    <dt>Sandbox and Production</dt>
    <dd>Two environments with separate keys, apps and models. Configuration never leaks across.</dd>
  </div>
  <div>
    <dt>Durable runs</dt>
    <dd>Each step is saved before it's taken. An interrupted run resumes, and a tool call is never sent twice.</dd>
  </div>
  <div>
    <dt>Your models</dt>
    <dd>Connect OpenAI, Anthropic or OpenRouter per environment and pick a model per agent.</dd>
  </div>
  <div>
    <dt>Signed webhooks</dt>
    <dd>Runs, approvals and connected accounts, delivered at least once and retried for a day.</dd>
  </div>
  <div>
    <dt>A full audit log</dt>
    <dd>Every change, with who made it and where, kept even after a workspace is gone.</dd>
  </div>
</dl>
